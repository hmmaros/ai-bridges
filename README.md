# 🌉 AI Bridges

AI harnesses και guides για ανθρώπους χωρίς τεχνικές γνώσεις.

## 📖 Τι είναι αυτό;

Μια συλλογή από **AI harness files** - οδηγοί που βοηθούν ανθρώπους χωρίς τεχνικές γνώσεις να φτιάξουν projects χρησιμοποιώντας AI tools (ChatGPT, Claude, OpenCode, κλπ).

## 🎯 Σκοπός

- Να γεφυρώσει το χάσμα μεταξύ AI και μη-τεχνικών χρηστών
- Να προσφέρει απλούς, βήμα-προς-βήμα οδηγούς
- Να κάνει τα projects προσιτά σε όλους

## 📚 Οδηγοί

### [project-guide.md](./project-guide.md)
Ο γενικός οδηγός για να φτιάξεις οποιοδήποτε project:
- Web apps (απλές ή πολύπλοκες)
- Telegram bots
- Blogs
- Games
- APIs
- Και άλλα...

**Ροή:**
1. 💡 Ιδέα & Scope
2. 🏠 Deployment (Local/Cloud/Server)
3. 🛠️ Stack Selection (HTML/React/Next.js/etc)
4. ✅ Acceptance Tests
5. 🔨 Implementation (βήμα-βήμα)
6. 🚀 Deployment
7. 🔄 Post-launch (backup, monitoring, updates)

**Features:**
- Επιλογή γλώσσας (Ελληνικά/English)
- Budget-aware recommendations
- Token cost tracking
- Flexibility (undo, skip, pivot)
- State management
- Error recovery

## 🚀 Πώς να χρησιμοποιήσεις

1. Κατέβασε έναν οδηγό (π.χ. `project-guide.md`)
2. Άνοιξε ένα AI tool (ChatGPT, Claude, OpenCode, κλπ)
3. Πες: **"διάβασε το project-guide.md"**
4. Ακολούθησε τις οδηγίες

## 🤝 Συνεισφορά

Αν έχεις ιδέες ή θέλεις να προσθέσεις οδηγούς:
- Κάνε fork
- Πρόσθεσε τα αρχεία σου
- Στείλε PR
